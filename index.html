주차별 스냅샷

이카운트 전체 재고 조회

날짜를 고르고 「조회」를 누르세요. 오늘은 현재 연동 자료, 지난 날짜는 그날 마지막으로 올라온 연동 자료(깃허브 이력)를 이카운트 전체 품목으로 보여줍니다.

전산재고

실물재고
입력칸은 빈칸으로 시작합니다. 이전 날짜에 확인한 값(없으면 전산재고로 계산한 추정값)은 입력칸에 흐린 글씨로만 보이며 저장·공유되지 않습니다. 실제 무게를 입력하거나, 흐린 값이 맞으면 「✓ 이전값 그대로」·「✓ 추정값 그대로」를 누르면 확인 완료로 바뀝니다. 소비기한은 이전 실물재고 작업의 날짜를 그대로 보여 주며, 고치면 이 날짜 값으로 저장됩니다. 확인된 뒤에도 값을 고치면 바로 저장·공유됩니다(버튼에 「✓ 저장됨 시각」 표시). 미개봉 1포 무게가 규격과 다른 품목은 「✎ 1포 무게 · 규격」(또는 설정 → 품목 표의 「1포 실중량」·「규격」)에 실제 계산 무게를 넣으면 모든 기기에서 그 무게로 계산합니다. 규격이 여러 종인 품목(예: 미로와데코젤·연유)은 같은 창에서 「＋ 규격 추가」로 규격별 1포 무게를 넣으면 규격별 미개봉 포수 칸이 따로 나옵니다. 「PDF 보고서」는 실물재고·소비기한 임박 순 보고서를 PDF로 만들어 휴대폰에 저장하거나 카카오톡으로 바로 보냅니다. 「PC로 보내기」는 입력한 실물 데이터를 문자로 복사합니다. 카톡 나와의 채팅으로 보낸 뒤 PC의 비교분석 → 「실물 가져오기」에 붙여넣으면 됩니다.
주간 재고 현황
조회 조건:
기준일 → 현재
조회 조건(기본: 품목명에 「gg」 포함, 「조건 편집」에서 추가·변경·삭제)에 맞는 관리 품목 중, 기준일과 현재 사이에 이카운트 전산재고가 바뀐 품목만 골라 현재 날짜의 실물을 입력합니다. 입력값은 실물입력 화면과 같은 저장소(현재 날짜)에 저장되어 비교분석·보고서에 그대로 반영됩니다. 기준일 전산은 깃허브 연동 이력(2026-09-09 이후)에서, 그 이전은 주간 업로드 스냅샷에서 가져옵니다.

원료 전산·실물 재고 비교분석

비교분석

차이 = 실물 − 전산. 조정대상 = |차이|가 허용오차(설정)를 넘는 품목. 조정수량을 이카운트 재고조정에 그대로 입력하면 됩니다.

주차별 추이

주간증감 = 이번 주 전산재고 − 지난 주 전산재고 (+입고 초과 / −사용 초과). 품목을 누르면 상세가 열립니다.

자가사용전표(ESM004E) 업로드

이카운트 자가사용전표 출력 엑셀을 여기에 놓거나
전표번호가 같으면 갱신됩니다. 음수가 있거나 출고창고가 「원료_…」인 전표는 자동으로 「조정」, 나머지는 「실사용」으로 분류하며 아래 목록에서 바꿀 수 있습니다.

원료 재고조정 이력 분석

품목별 조정 패턴

＋ = 실물이 전산보다 적어 전산을 줄인 조정(사용 미등록·입고 중복 의심), − = 실물이 전산보다 많아 전산을 늘린 조정(빈용기·규격·BOM 의심). 같은 방향이 반복되면 측정 오차가 아니라 구조적 원인입니다. 품목을 누르면 전표별 사유를 기록할 수 있습니다.

품목 마스터 · 규격 · g단가

이카운트 품목등록(ESA009M) 엑셀을 여기에 놓거나
제품규격 → 규격(g), 보관포장무게 → 빈용기(g), 입고단가 → g단가(원). 아래 표에서 직접 고칠 수 있고, 단가는 비교분석·재고조정의 금액 계산에 쓰입니다.
실물입력·비교에서 제외할 품목은 「사용」을 끕니다. (전산재고 표에는 그대로 표시) 노란 칸은 값이 없는 항목입니다.

🔐 비밀번호 · 화면 모드

비밀번호 하나로 전체가 열립니다. 원료수불부 · 완제품·생지 · 육안검사 · 생산일지는 이 시스템을 열 때 넣은 비밀번호 하나를 같이 씁니다(각 화면에서 따로 묻지 않음). 「이 기기에 기억」을 켜 두면 다음부터는 묻지 않습니다.

👤 로그인 계정 · 접속 이력

직원마다 아이디·비밀번호를 따로 만들 수 있습니다. 계정은 이카운트 중계에 잠긴 채로 보관되고(비밀번호 자체는 어디에도 저장하지 않음), 지우면 그 아이디로는 더 이상 로그인할 수 없습니다. 대표 아이디 「빵을그리다」는 지금의 재고 비밀번호로도 들어올 수 있습니다.
접속 이력
「불러오기」를 누르면 모든 기기의 로그인 기록이 나옵니다. (창을 새로 열어 로그인할 때마다 1건, 새로고침은 기록하지 않음)

기본 정보

|차이| 가 g 기준과 % 기준(전산재고 대비) 중 하나라도 넘으면 조정대상으로 표시합니다. 둘 다 0이면 차이가 있는 모든 품목이 조정대상입니다.

공유 저장소 (구글 시트)

실물재고·소비기한·메모 입력값을 구글 시트에 모아 담당자 휴대폰·사무실 PC·다른 열람자가 같은 값을 보게 합니다. 시트에 붙인 Apps Script 웹 앱 URL을 넣으면 입력 즉시 올라가고 1분마다 받아옵니다. 같은 품목·날짜는 나중에 입력한 값이 우선하며 입력자 이름이 함께 기록됩니다.

데이터 저장 · 백업

「데이터 포함 HTML 저장」으로 내보낸 파일은 비밀번호로 잠겨서 나갑니다. 비밀번호를 모르면 열 수 없으니 잊지 않도록 적어 두세요. 「이 기기에서 잠그기」를 누르면 이 기기에 기억된 비밀번호가 지워져, 다음에 열 때 다시 물어봅니다.
브라우저에 자동 저장됩니다. 다른 PC·휴대폰과 공유하려면 「데이터 포함 HTML 저장」 후 그 파일을 Google Drive에 올려 열면 됩니다. 저장된 HTML은 열 때 내장 데이터가 브라우저 데이터보다 최신이면 내장 데이터를 사용합니다.
